## 🚀 One-Line Installation

Run this command in Termux to launch the installer directly:

```bash
curl -sL [https://raw.githubusercontent.com/TBF-official/tbf-setup/main/tbf-setup.sh](https://raw.githubusercontent.com/TBF-official/tbf-setup/main/tbf-setup.sh) | bash

🛠 Manual Setup
If you prefer to clone and run the script manually:
# 1. Clone the repository
git clone https://github.com/TBF-of/Termux-setup.git

# 2. Enter the directory
cd tbf-setup

# 3. Make the script executable and run
chmod +x tbf-setup.sh
./tbf-setup.sh

✨ Features
 * Interactive Menu: Toggle packages with [✓] (install) or [✗] (skip) using simple numbers.
 * Smart Error Handling: If a package fails, you can retry [y], skip [n], or type a custom name [u].
 * Clean UI: Colorized output (green for success, red for errors) with a progress counter.
